# Patrones Hermosos · beautifulpatterns.org

Sitio web de Patrones Hermosos.

## Contenido

- `index.html`, `bootcamp.html`, `anfitriones.html`, `equipo.html`, `nosotras.html`, `oportunidades.html`: páginas del sitio
- `bootcamps.json`, `convocatorias.json`, `careers.json`, `redes.json`: contenido de sedes, convocatorias, oportunidades y redes
- `translations.json`, `i18n.js`: textos en español e inglés
- `site.js`, `styles.css`: comportamiento y estilos
- `assets/`: imágenes
